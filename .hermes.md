# hermes-artifacts

Interactive artifact boards (single-file HTML + collectors).

## Layout
`artifact.json` / template / data / index. Collectors under `tools/collectors/` are **stdlib-only**. Refresh: `tools/refresh.py` using the FinancialDevelopment venv when a collector needs FD data.
