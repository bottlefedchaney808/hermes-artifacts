# hermes-artifacts

Interactive artifact boards (single-file HTML + collectors).

## Layout
`artifact.json` / template / data / index. Collectors under `tools/collectors/` are **stdlib-only**. Refresh: `tools/refresh.py`, run from the repo-local `.venv` (`make test` / `make refresh`). FinancialDevelopment is a data source, not an interpreter.

## Compact-row
Model-usage board compact-row field semantics: see the 2026-09-06 fix. Skill: `hermes-interactive-artifacts`. Do not duplicate the plugin install here.
